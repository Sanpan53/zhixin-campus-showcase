## 上传与演示步骤

1. 使用 `admin / demo123` 登录。
2. 进入“知识库管理”，按上表选择对应知识库。
3. 上传普通文档时，文档类型选择“自动识别”或“普通文档”。
4. 上传 `qa/04-校园服务问答.md` 时，选择“QA/FAQ 文档”，上传后查看 QA 校验报告。
5. 等待文档状态变为“已完成”，打开 Chunk 窗口检查分块边界。
6. 在“智能问答”中提问，例如：
   - “宿舍钥匙忘带了可以借多久？”
   - “换宿舍需要经过哪些人批准？”
   - “本科生一次能借几本书？”
   - “B+ 树索引和哈希索引有什么区别？”
7. 检查回答中的引用编号，以及右侧来源卡片对应的文档、章节和摘要。

## 评估数据

`eval/questions.jsonl` 共 10 题，其中 `dev` 8 题、`holdout` 2 题。每题包含：

- `question`：用户问题；
- `expected_answer`：参考答案，用于忠实性评估；
- `source_document` / `source_anchor`：定位提示；
- `expected_chunk_ids`：当前为 `null`，需要在当前索引版本中人工标注；
- `review_status`：`pending_chunk_annotation`。

**未完成 `expected_chunk_ids` 标注时，Hit Rate 和 MRR 会被计为 0，这不是系统效果差，而是评估数据还没有 ground truth。** 标注步骤见项目 `PROJECT_CASE.md` 的“效果评估”一节。
